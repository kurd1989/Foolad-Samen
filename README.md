# سامانه ثبت گزارش خط تولید میلگرد
## فولاد ثامن پایتخت

نرم‌افزار موبایل (APK) برای ثبت گزارش‌های عملیاتی اپراتورهای خط تولید میلگرد.

---

## شرایط کاری پشتیبانی‌شده

| مورد | مقدار |
|------|--------|
| چرخه شیفت | ۲ روز روزکار → ۲ روز شب‌کار → ۲ روز استراحت |
| شیفت روزکار | ۰۷:۰۰ تا ۱۹:۰۰ |
| شیفت شب‌کار | ۱۹:۰۰ تا ۰۷:۰۰ |
| دسترسی | هر اپراتور فقط بخش خودش را می‌بیند |

---

## بخش‌ها و فرم‌ها

| بخش | فرم |
|-----|-----|
| خط نورد | چک‌لیست خط نورد (رافینگ + استند ۱ تا ۱۲) |
| تراشکاری | گزارش کار روزانه پرسنل |
| هادی‌سازی | گزارش تعویض جعبه، ناخنی، لوله، کنسولی |
| کوره | چک‌لیست توقفات و علت سردی |

---

## تست سریع (بدون ساخت APK)

```bash
cd steel-app
python3 -m http.server 8080
```

سپس در مرورگر موبایل آدرس را باز کنید و از منوی مرورگر **Add to Home Screen** را بزنید.

---

## ساخت فایل APK واقعی

### روش ۱: با اسکریپت (پیشنهادی)

```bash
cd steel-app
./build-apk.sh
npx cap open android
```

سپس در Android Studio از منوی **Build → Build APK(s)** استفاده کنید.

جزئیات کامل در فایل `SETUP-APK.md` نوشته شده است.

### روش ۲: دستی

```bash
npm install
npx cap add android
npx cap sync
npx cap open android
```

### روش ۳: سریع با PWA Builder

1. پروژه را روی اینترنت قرار دهید
2. به سایت https://www.pwabuilder.com بروید
3. آدرس را وارد کنید و APK را دانلود کنید
